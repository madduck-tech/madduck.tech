# Mad Duck — Image Generation Prompt Guide

Use this file as the base prompt for future Mad Duck illustrations, project covers and article images.

The visual identity is always:

**black-and-white editorial imagery + a black duck + exactly one intentional yellow accent.**

## Master prompt

Create a high-resolution editorial image for the Mad Duck technology workshop.

The central recurring character is a **black duck** with a mischievous, confident, slightly aggressive personality. The duck may wear practical workwear, sunglasses, a jacket, helmet, or technical equipment depending on the scene.

Visual style:
- predominantly black and white;
- gritty independent engineering magazine;
- underground technical zine;
- bold ink illustration mixed with documentary photography;
- xerox / photocopy texture;
- screen-print texture;
- halftone grain;
- rough black ink;
- imperfect paper texture;
- high contrast;
- strong silhouettes;
- realistic but stylized;
- slightly absurd, intelligent humor;
- editorial composition;
- not cute;
- not glossy;
- not 3D;
- not generic AI art.

Important color rule:

**The entire image must remain monochrome except for exactly ONE yellow detail.**

Use a saturated print yellow close to `#FFD400`.

The yellow element must be a real object or meaningful visual detail in the scene, such as:
- one helmet;
- one sunglasses lens/reflection;
- one scarf;
- one cable;
- one sign;
- one tool;
- one flower;
- one sticker;
- one small light source.

Do not scatter yellow around the image.
Do not add secondary accent colors.

Composition:
- cinematic but graphic;
- strong negative space where useful;
- asymmetry is welcome;
- cropped editorial framing;
- suitable for website hero/project/article artwork;
- readable at both desktop and card size;
- avoid tiny visual clutter.

Texture:
- analog print;
- newspaper;
- rough grain;
- slightly distressed edges;
- imperfect ink coverage;
- visible halftone where appropriate.

Mood:
- independent;
- clever;
- technical;
- rebellious;
- dry humor;
- practical rather than futuristic.

Avoid:
- Disney-like duck characters;
- DuckTales resemblance;
- Pixar;
- soft children's illustration;
- anime;
- glossy 3D rendering;
- cyberpunk neon;
- gradients;
- purple, cyan, red or blue accents;
- generic startup illustration;
- clean corporate vector art;
- excessive sci-fi holograms;
- cute mascot proportions.

No text inside the image unless explicitly requested.

## Short reusable prompt

Black-and-white gritty editorial illustration/photo-collage for Mad Duck: a mischievous black duck in an independent engineering/workshop scene, high-contrast ink, xerox, halftone, newspaper grain, rough print texture, asymmetric composition, technical and slightly punk mood. Exactly one object/detail is bright yellow `#FFD400`; everything else stays monochrome. No other colors, no gradients, no glossy 3D, no cute/cartoon Disney look, no generic AI-startup aesthetic.

## Aspect ratio guidance

Use depending on placement:

- Hero: `16:9` or `3:2`
- Project card: `4:3`
- Article card: `3:2`
- Portrait mascot: `4:5`
- Social preview / OG: `1.91:1`

Generate at the highest practical resolution and crop afterward rather than generating tiny source images.

## Consistency checklist

Before accepting an image:

- Is the duck black?
- Is the image visually monochrome?
- Is there exactly one yellow accent?
- Is the yellow meaningful rather than decorative noise?
- Does the image look printed/editorial rather than polished digital art?
- Is it free of blue/purple/red accent contamination?
- Does it avoid cute Disney/Pixar styling?
- Does it fit an independent engineering workshop?
- Does it still work when shown small on a website card?

If not, regenerate.
